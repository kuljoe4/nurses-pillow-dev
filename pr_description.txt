💡 What: Optimized array filtering in GoogleHospitalAutocomplete by pre-computing lowercased string arrays in a separate useMemo block.
🎯 Why: Calling .toLowerCase() inside array.filter() is inefficient for rapid user search input, as it re-allocates strings every keystroke.
📊 Impact: Reduces repetitive string allocation inside the React component loop during rapid search, improving typing performance in the hospital autocomplete dropdown.
🔬 Measurement: Typing in the hospital autocomplete is visibly faster and profiles show fewer repetitive string allocations on each keystroke.
